### The Architecture for Subject-Wise Grades

**1. Data Extraction (The Hard Part)**
Result PDFs from universities are notoriously messy. We would need to write a custom script (using a library like `pdf2json` in Node.js, or `pdfplumber` in Python) that loops through every single semester PDF you upload. It would scan the tables, extract the Roll Number, Name, Subject Codes, and Grades.

**2. Data Structuring**
Instead of just storing the overall CGPA, our script would generate a highly detailed `transcripts.json` file. For every student, it would look something like this:
```json
{
  "rollNumber": "2K22/SE/123",
  "name": "John Doe",
  "semesters": {
    "sem1": {
      "sgpa": 8.5,
      "subjects": [
        { "code": "MA101", "name": "Mathematics I", "grade": "A", "credits": 4 },
        { "code": "PH101", "name": "Physics", "grade": "B+", "credits": 4 }
      ]
    }
  }
}
```
